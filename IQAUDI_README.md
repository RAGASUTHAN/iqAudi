# iqAudi Security Testing

A rebranded, premium-themed security testing interface built from the open-source Strix engine.

- Product/UI name: **iqAudi**
- Theme: deep-black glass UI with cyan + violet accents
- Engine compatibility: underlying `strix` Python modules and `STRIX_*` runtime settings are preserved internally
- Render-ready viewer: `render.yaml` + `render_server.py`
- Local engine requirements: Python 3.12+, Docker, and an LLM provider key

> **Important:** This project retains the original Apache-2.0 license and upstream notices. Rebranding the UI does not transfer copyright or remove the upstream license requirements.
